# Logistics Cost Analyzer

A web-based logistics cost analysis application built with **Flask** that enables users to upload logistics datasets, analyze transportation costs, and visualize key insights through interactive dashboards. The application is designed to help logistics professionals, students, and analysts make data-driven decisions by identifying cost patterns and operational trends.

---

## Features

- Upload logistics datasets in Excel format
- Automatically process and analyze logistics data
- Interactive charts and visualizations using Plotly
- Cost distribution analysis
- Shipment and transportation cost insights
- Clean and responsive web interface
- Downloadable analysis results (if enabled)

---

## Dashboard Overview

The application provides visual insights into logistics operations, including:

- Transportation cost distribution
- Shipment analysis
- Cost comparison
- Operational performance indicators
- Interactive charts and graphs

> **Note:** Dashboard metrics depend on the uploaded dataset.
